
### Problem `(required)`

```
- Pressing "Confirm Payment" on an impounding record throws: Illuminate\Contracts\Container\BindingResolutionException
- Error: "Target class [App\Http\Controllers\PaymentRecorder] does not exist."
- Location: http://127.0.0.1:8000/impounding/{id}/mark-paid → ImpoundingController@markPaid → line 228
- The controller resolves `App\Http\Controllers\PaymentRecorder` instead of `App\Services\PaymentRecorder` because the service import is missing.
```

### Root Cause `(required)`

```
- app/Http/Controllers/ImpoundingController.php:228 calls `app(PaymentRecorder::class)->recordImpounding(...)`.
- The controller is missing the `use App\Services\PaymentRecorder;` import statement.
- Because ImpoundingController is in namespace `App\Http\Controllers` and has no `use` alias for PaymentRecorder, PHP/Laravel resolves `PaymentRecorder` to `App\Http\Controllers\PaymentRecorder`, which does not exist.
- The sibling controllers ClampingController (line 16) and PaymentController (line 14) both import `App\Services\PaymentRecorder` correctly — ImpoundingController was simply missing it.
```

# Fix Citizen Portal Clamping Search by Vehicle Plate (Undefined Column Error)

### Date Edited / Applied `(required)`

```
- Edited and applied: 2026-11-11
```

### Type of Change `(required)`

```
- Bug fix
```

### Requested By / Source `(optional)`

```
- Observed at http://127.0.0.1:8000/citizen/citation/lookup — clicked "Clamping" tab → searched a clamping ticket → POST /citizen/clamping/search → 500 Internal Server Error
```

### Problem `(required)`

```
- Searching for a clamping ticket by vehicle plate throws: Illuminate\Database\QueryException — SQLSTATE[42703]: Undefined column: 7 ERROR: column "vehicle_plate" does not exist
- Location: http://127.0.0.1:8000/citizen/clamping/search → CitizenPortalController@clampingSearch → line 128
- The search query references vehicle_plate directly on the clamping_records table, but that column was dropped by migration 2026_10_22_052745_drop_redundant_columns_from_clamping_and_impounding_records.php (P7 deduplication)
```

### Root Cause `(required)`

```
- app/Http/Controllers/CitizenPortalController.php:128 calls ->orWhere('vehicle_plate', 'like', "%{$search}%") directly on ClampingRecord query
- The vehicle_plate column no longer exists on the clamping_records table (dropped in migration 2026_10_22)
- vehicle_plate now lives on the citations table, and each clamping record is linked to a citation via the citation() relationship (BelongsTo)
- The ClampingRecord model already has a getVehiclePlateAttribute() accessor (lines 121-124) that reads vehicle_plate from the linked citation — but accessors are PHP-level and cannot be used in SQL WHERE clauses
```

### Files Changed `(required)`

- `C:\xampp\htdocs\TEMS\app\Http\Controllers\CitizenPortalController.php`
- `C:\xampp\htdocs\TEMS\documents\11_11_2026.md` (this document)

### What Parts Changed `(required)`

#### `C:\xampp\htdocs\TEMS\app\Http\Controllers\CitizenPortalController.php`

**Before:**
```php
            ->where(function ($query) use ($search) {
                $query->where('notice_number', 'like', "%{$search}%")
                    ->orWhere('vehicle_plate', 'like', "%{$search}%");
            })
```

**After:**
```php
            ->where(function ($query) use ($search) {
                $query->where('notice_number', 'like', "%{$search}%")
                    ->orWhereHas('citation', function ($q) use ($search) {
                        $q->where('vehicle_plate', 'like', "%{$search}%");
                    });
            })
```

### Behavior of the New Changes `(required)`

| Scenario | Before | After |
|---|---|---|
| Search clamping by notice number (e.g. CLP-...) | Works | Works (unchanged) |
| Search clamping by vehicle plate | 500 Error: column "vehicle_plate" does not exist | Searches citations.vehicle_plate through citation relationship; returns matching clamping record |
| ClampingRecord::with(['citation']) eager load | Already present on line 125 | Unchanged — citation is already eager-loaded |

### Impact & Risk `(required)`

```
- Affects: http://127.0.0.1:8000/citizen/clamping/search — Citizen Portal clamping lookup by vehicle plate only
- Risk: Low. Query-only change using existing citation() relationship. No schema changes, no migration needed, no data redundancy introduced.
- The citation relationship is already eager-loaded via ->with(['citation', ...]) on line 125, so no N+1 query issue.
- Other pages querying vehicle_plate on citations/citizen_reports/etc. are unaffected — those columns still exist.
```

### Database / Migration Impact `(optional)`

```
- None. Purely an Eloquent query builder change; no schema, seeders, or migrations touched.
- Does NOT re-add the dropped vehicle_plate column to clamping_records — preserves the P7 deduplication design where vehicle_plate is single-sourced from citations.
```
